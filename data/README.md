# Thirukkural data

`kurals.json` contains the 1,330 original Tamil couplets and the English
couplets attributed to G. U. Pope. It is a reduced copy of the
[tk120404/thirukkural](https://github.com/tk120404/thirukkural) dataset, which
is distributed under the Apache License 2.0. The underlying literary works are
also available through [Project Madurai](https://www.projectmadurai.org/).
